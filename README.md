Custom Web Music Player: 🎵
A custom, Spotify-inspired web music player and playlist application built with a personalized girly theme. Designed and developed as part of the Decode Labs internship.

 Features:
Custom UI / Theme: A sleek, personalized interface featuring custom layouts, smooth banners, and typography styled for a unique personal aesthetic.

Interactive Playlist Navigation: Seamlessly switch between the home screen, playlist grids, and detailed song views using custom buttons and JavaScript event handlers.

Dynamic Audio Control: Custom-built track management supporting audio playback logic.

Smooth Animations: Integrated CSS keyframe animations and transitions for polished UI feedback.

 Tech Stack:
HTML5 (Semantic structure)

CSS3 (Flexbox, Grid, custom animations, and responsive styling)

JavaScript (DOM manipulation and navigation logic)
